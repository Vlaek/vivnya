# Vivnya Portfolio

The official web portfolio of artist Milana Zubareva, also known as Vivnya. The site presents selected character art, illustration projects, comics, and process work in a bilingual Russian and English experience.

## Technology

- React and TypeScript
- Vite
- Tailwind CSS
- i18next
- Vitest and Testing Library
